# zapret-discord-youtube

Набор средств и BAT-скриптов для Windows, предназначенный для работы с ограничениями сетевого доступа к Discord и YouTube. Результат зависит от сети, провайдера и выбранной стратегии; универсальная работоспособность не гарантируется.

Проект основан на [zapret-discord-youtube от Flowseal](https://github.com/Flowseal/zapret-discord-youtube). Публикуемая версия файлов — [1.10.2](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.2).

## Быстрый старт

1. Откройте [релиз 1.10.2](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.2) и скачайте опубликованный архив проекта.
2. В свойствах архива Windows при наличии установите флажок **Разблокировать**. При распаковке через 7-Zip или PeaZip этот шаг обычно не требуется.
3. Распакуйте архив в папку без кириллицы, пробелов и нестандартных символов, например:

   ```text
   C:\DiscordFix\
   ```

4. Для ручного запуска от имени администратора откройте папку проекта и запустите подходящий `general*.bat`.
5. Если нужна работа через службу Windows, запустите `service.bat` от имени администратора и выберите установку службы и стратегии.
6. Проверьте Discord и YouTube. Если выбранная стратегия не помогает, остановите её и протестируйте другой вариант `general*.bat`.

Не запускайте одновременно несколько ручных стратегий. Для работы скриптов используется `WinDivert`, поэтому защитное ПО может отдельно предупреждать об этом компоненте.

## Требования и ограничения

Проект предназначен для Windows и использует системный компонент `WinDivert` для перехвата и обработки сетевого трафика. BAT-скрипты и диагностику обычно требуется запускать от имени администратора.

Работа зависит от сетевых условий, провайдера и конфигурации. Переименование репозитория не изменяет программу и не добавляет собственный установщик, EXE-файл или новые платформы.

Перед запуском проверяйте происхождение архива. Некоторые защитные программы могут классифицировать `WinDivert` как потенциально нежелательный инструмент или обнаружение вида `Not-a-virus:RiskTool.Multi.WinDivert`. Подробности приведены в документации [zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B).

Бинарные компоненты каталога [`bin`](./bin) основаны на материалах [zapret-win-bundle/zapret-winws](https://github.com/bol-van/zapret-win-bundle/tree/master/zapret-winws) и [релизов zapret](https://github.com/bol-van/zapret/releases).

## Настройка DNS

Для отдельных ресурсов может потребоваться Secure DNS, также называемый DNS over HTTPS.

- В Chrome откройте настройки безопасного DNS и выберите конкретного поставщика.
- В Firefox включите DNS через HTTPS, выберите ручного поставщика и укажите, например, `https://dns.google/dns-query`.
- В Windows 11 Secure DNS настраивается в системных параметрах.
- На роутере Keenetic проверьте параметр **«Транзит запросов»**: его отключение может мешать работе Secure DNS на компьютере.

## Ручной запуск стратегий

`general*.bat` предназначены для ручного запуска стратегий. В папке могут присутствовать варианты `ALT`, `FAKE`, `SIMPLE FAKE`, `EXP` и другие конфигурации. Выбирайте стратегию по инструкции проекта и учитывайте, что результат может различаться у разных провайдеров.

После запуска стратегии должен появиться процесс `winws.exe`. Для остановки ручной стратегии используйте предусмотренный скриптом способ или закройте запущенный процесс перед тестированием другого варианта.

## Работа через службу

`service.bat` используется для управления службой, диагностикой и дополнительными настройками. Доступные пункты включают:

- **`Install Service`** — добавить выбранную стратегию в автозапуск Windows;
- **`Remove Services`** — удалить созданные службы и WinDivert;
- **`Check Status`** — проверить состояние служб и активной конфигурации;
- **`Run Diagnostics`** — выполнить диагностику распространённых причин неправильной работы;
- **`Run Tests`** — запустить проверку доступных стратегий;
- **`Game Filter`** — настроить обработку игрового трафика UDP/TCP;
- **`IPSet Filter`** — выбрать режим фильтрации адресов из `ipset-all.txt`;
- **`Update IPSet List`** — обновить `ipset-all.txt`;
- **`Update Hosts File`** — обновить hosts для отдельных Telegram-ресурсов и голосовых подключений Discord;
- **`Replace active fakes`** — заменить используемый fake-файл вариантом из `bin`;
- **`Auto-Update Check`** и **`Check for Updates`** — проверить доступность обновлений.

`Install Service` относится к работе через службу и не заменяет ручной запуск `general*.bat`. После изменения фильтров или стратегии может потребоваться повторный запуск активной конфигурации.

### IPSet Filter

Режимы фильтрации:

- `none` — IP-адреса не используются;
- `loaded` — обрабатываются адреса из списка;
- `any` — под фильтрацию попадает любой IP.

Режим `any` может затронуть соединения, которые не должны обрабатываться, поэтому его не рекомендуется использовать постоянно.

### Run Tests

- **Standard tests** проверяет ресурсы из `utils/targets.txt`.
- **DPI checkers** выполняет дополнительные проверки DPI для разных сетевых условий.

## Устранение проблем

### `general*.bat` не запускает стратегию

**Симптом:** процесс `winws.exe` не появляется или сразу завершается.

**Проверьте и сделайте следующее:**

1. Запустите BAT-файл от имени администратора.
2. Протестируйте другую стратегию.
3. Запустите `service.bat` → **`Run Diagnostics`**.
4. Сверьте ситуацию с обсуждением [#522](https://github.com/Flowseal/zapret-discord-youtube/issues/522).

### Ни одна стратегия не работает

Откройте командную строку от имени администратора и выполните:

```cmd
netsh winsock reset
netsh int ip reset all
netsh winhttp reset proxy
ipconfig /flushdns
```

Перезагрузите Windows и повторите проверку нескольких стратегий.

### Discord не подключается

Проверьте Secure DNS, запустите `service.bat` → **`Run Diagnostics`**, очистите кэш Discord и протестируйте другую стратегию. Также проверьте веб-версию: [discord.com/app](https://discord.com/app). Если веб-версия работает, причина может быть связана с локальными данными приложения. Дополнительное обсуждение: [#252](https://github.com/Flowseal/zapret-discord-youtube/discussions/252).

### YouTube не открывается

Проверьте Secure DNS, протестируйте другую стратегию и убедитесь, что подключению не мешает сторонний блокировщик рекламы. Дополнительная информация: [#251](https://github.com/Flowseal/zapret-discord-youtube/discussions/251).

### Не работает Telegram Web или голосовой Discord

Откройте `service.bat` → **`Update Hosts File`**. Если скрипт предлагает изменить hosts вручную:

1. скопируйте предложенное содержимое;
2. откройте файл `hosts` с правами администратора;
3. добавьте необходимые строки и сохраните файл;
4. повторно проверьте подключение.

Для Telegram Desktop предусмотрено отдельное решение [TG WS Proxy](https://github.com/Hidefapinpoint/tg-ws-proxy).

### Не работают игры или конфликтует приложение

Через `service.bat` обновите IPSet, проверьте **`Game Filter`** и **`IPSet Filter`**, затем протестируйте несколько стратегий. Чтобы исключить влияние фильтрации, временно установите **`Game Filter`** в `disabled`, а **`IPSet Filter`** — в `none`.

Если игре нужны определённые адреса, их можно добавить в `ipset-all.txt`. Обсуждение проблем с конкретными играми: [Discussions](https://github.com/Flowseal/zapret-discord-youtube/discussions).

### Стратегия перестала работать

Сетевые условия могут измениться. Попробуйте другую стратегию, запустите **`Run Diagnostics`**, обновите IPSet и hosts, а затем повторите тестирование.

Описание параметров стратегий доступно в документации оригинального [zapret](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

### WinDivert остался после удаления службы

Откройте `cmd` и выполните:

```cmd
driverquery | find "Divert"
```

Для найденной службы выполните:

```cmd
sc stop название_службы
sc delete название_службы
```

Для Windows 7 сведения о версиях WinDivert находятся в разделе [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7). Информация о специальной конфигурации для античита: [windivert-hide](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide).

## Пользовательские списки

Дополнительные домены и IP-адреса можно указывать в следующих файлах:

- `list-general-user.txt` — пользовательские домены и поддомены;
- `list-exclude-user.txt` — домены-исключения;
- `ipset-all.txt` — IP-адреса и подсети;
- `ipset-exclude-user.txt` — исключения для IP-адресов и подсетей.

Файлы с суффиксом `-user` создаются автоматически при первом запуске `zapret` или `service.bat`.

## Обновление

1. Сохраните собственные изменения и пользовательские списки.
2. Перезагрузите Windows.
3. Откройте `service.bat` → **`Remove Services`**.
4. Запустите **`Run Diagnostics`**.
5. Удалите старую папку проекта.
6. Скачайте архив из раздела [Releases](https://github.com/Flowseal/zapret-discord-youtube/releases).
7. При необходимости разблокируйте архив в свойствах Windows.
8. Распакуйте новую версию в отдельную папку.
9. Протестируйте несколько `general*.bat`.
10. После выбора стратегии при необходимости используйте **`Install Service`**.
