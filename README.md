# zapret Discord YouTube для Windows

Этот репозиторий содержит файлы и BAT-скрипты проекта на основе [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube). Проект предназначен для проверки сетевых стратегий при ограничениях доступа к Discord и YouTube в Windows.

Результат зависит от сети, провайдера и выбранной стратегии. Универсальная работоспособность для всех сетей не гарантируется.

## Быстрый старт

1. Откройте страницу базового релиза [1.10.2](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.2) и скачайте опубликованный архив.
2. В свойствах архива Windows при наличии установите флажок **«Разблокировать»** и примените изменения. При распаковке через 7-Zip или PeaZip этот шаг обычно не требуется.
3. Распакуйте архив в каталог без кириллицы, пробелов и нестандартных символов, например:

   ```text
   C:\DiscordFix\
   ```

4. Запустите подходящий файл `general*.bat` от имени администратора. Эти файлы предназначены для ручного запуска стратегий.
5. Проверьте доступ к Discord и YouTube. Если выбранная стратегия не помогает, завершите её работу и протестируйте другой вариант.

Не запускайте неизвестные файлы из сторонних архивов. Используйте файлы из опубликованного репозитория и его раздела Releases.

## Требования и ограничения

Проект рассчитан на Windows и использует WinDivert для перехвата и обработки сетевого трафика. Защитные программы могут обнаруживать компоненты с упоминанием `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`. Такая классификация сама по себе не подтверждает наличие вредоносного кода, но происхождение архива необходимо проверять.

Не отключайте защиту Windows и не добавляйте файлы в исключения без проверки источника и понимания последствий. Дополнительная информация о WinDivert приведена в документации [zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B).

Бинарные компоненты каталога `bin` основаны на материалах [zapret-win-bundle/zapret-winws](https://github.com/bol-van/zapret-win-bundle/tree/master/zapret-winws) и [релизов zapret](https://github.com/bol-van/zapret/releases).

## DNS и подготовка подключения

Для отдельных ресурсов рекомендуется настроить безопасный DNS — DNS over HTTPS.

- В Chrome откройте настройки безопасного DNS и выберите конкретного поставщика.
- В Firefox откройте настройки DNS через HTTPS, выберите ручного поставщика и укажите адрес, например `https://dns.google/dns-query`.
- В Windows 11 Secure DNS настраивается в системных параметрах.
- На роутере Keenetic проверьте параметр **«Транзит запросов»**: его отключение может мешать работе Secure DNS на компьютере.

## Ручной запуск стратегий

Файлы `general.bat` и другие файлы с шаблоном `general*.bat` запускают стратегии вручную. Одна стратегия может работать в конкретной сети лучше другой.

Если первый вариант не помогает, последовательно протестируйте доступные стратегии, включая варианты `ALT`, `FAKE`, `SIMPLE FAKE` и `EXP`, если такие файлы опубликованы в выбранной версии. Перед сменой стратегии остановите уже запущенный вариант.

При обычном запуске стратегии должен появиться процесс `winws.exe`. Для запуска BAT-файлов требуются права администратора.

## Запуск через службу Windows

Файл `service.bat` предназначен для управления службой и диагностики. Его пункты позволяют:

- **`Install Service`** — добавить выбранную стратегию в автозапуск Windows;
- **`Remove Services`** — удалить созданные службы и WinDivert;
- **`Check Status`** — проверить состояние служб и активной конфигурации;
- **`Run Diagnostics`** — выполнить диагностику распространённых причин неисправности;
- **`Run Tests`** — запустить проверку доступных стратегий.

Служба отличается от ручного запуска через `general*.bat`: после установки она работает через службу Windows, а не только пока открыта запущенная консоль. Сначала выберите рабочую стратегию ручным запуском, затем при необходимости используйте **`Install Service`**.

## Фильтры и списки адресов

`service.bat` также содержит пункты для настройки фильтрации:

- **`Game Filter`** — управление обработкой игрового трафика через UDP и TCP на соответствующих портах;
- **`IPSet Filter`** — включение или отключение фильтрации адресов из `ipset-all.txt`;
- **`Update IPSet List`** — обновление `ipset-all.txt`;
- **`Replace active fakes`** — смена используемого fake-файла на другой вариант из `bin`;
- **`Update Hosts File`** — обновление hosts для отдельных Telegram-ресурсов и голосовых подключений Discord;
- **`Auto-Update Check`** и **`Check for Updates`** — автоматическая и ручная проверка доступности обновлений.

Режимы `IPSet Filter`:

- `none` — IP-адреса не используются для фильтрации;
- `loaded` — проверяются адреса из списка;
- `any` — под фильтрацию попадает любой IP.

После изменения параметров может потребоваться повторный запуск активной стратегии. Режим `ipset any` способен затронуть соединения, которые не должны обрабатываться, поэтому его не следует использовать постоянно без необходимости.

Тесты включают **Standard tests** для ресурсов из `utils/targets.txt` и **DPI checkers** для дополнительных проверок DPI.

Пользовательские списки:

- `list-general-user.txt` — домены и поддомены;
- `list-exclude-user.txt` — исключаемые домены;
- `ipset-all.txt` — IP-адреса и подсети;
- `ipset-exclude-user.txt` — исключения для IP-адресов и подсетей.

Файлы с суффиксом `-user` создаются автоматически при первом запуске `zapret` или `service.bat`.

## Устранение проблем

### `general*.bat` не запускается или сразу завершается

Проверьте запуск от имени администратора, затем попробуйте другую стратегию. Если проблема сохраняется, запустите `service.bat` → **`Run Diagnostics`**. Дополнительное обсуждение: [Issue #522](https://github.com/Flowseal/zapret-discord-youtube/issues/522).

### Ни одна стратегия не помогает

Откройте командную строку от имени администратора и выполните:

```cmd
netsh winsock reset
netsh int ip reset all
netsh winhttp reset proxy
ipconfig /flushdns
```

Перезагрузите компьютер и повторите проверку нескольких стратегий.

### Не работает Telegram Web или голосовой Discord

Откройте `service.bat` → **`Update Hosts File`**. Если скрипт предлагает изменить hosts вручную:

1. скопируйте предложенное содержимое;
2. откройте файл `hosts` с правами администратора;
3. добавьте необходимые строки и сохраните файл;
4. повторно проверьте подключение.

### Не подключается Discord

Проверьте настройку Secure DNS, запустите `service.bat` → **`Run Diagnostics`**, очистите кэш Discord и протестируйте другую стратегию. Также проверьте веб-версию: [discord.com/app](https://discord.com/app). Если веб-версия работает, причина может быть связана с локальными данными приложения. Дополнительная информация: [Discussion #252](https://github.com/Flowseal/zapret-discord-youtube/discussions/252).

### Не открывается YouTube

Проверьте Secure DNS, протестируйте другую стратегию и убедитесь, что подключению не мешает сторонний блокировщик рекламы. Обсуждение проблемы: [Discussion #251](https://github.com/Flowseal/zapret-discord-youtube/discussions/251).

### Стратегия перестала работать

Сетевые условия могут измениться. Попробуйте другую стратегию, запустите **`Run Diagnostics`**, обновите IPSet и hosts, а затем повторите тестирование. Описание параметров стратегий доступно в документации оригинального [zapret](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

### Игра или приложение конфликтует с настройками

Проверьте **`Game Filter`** и **`IPSet Filter`**. Для проверки влияния фильтров временно установите **`Game Filter`** в `disabled`, а **`IPSet Filter`** — в `none`.

### WinDivert остался после удаления службы

Откройте `cmd` и выполните:

```cmd
driverquery | find "Divert"
```

Найдите имя соответствующей службы, затем выполните:

```cmd
sc stop название_службы
sc delete название_службы
```

### Windows 7 требует цифровую подпись WinDivert

Файлы `WinDivert.dll` и `WinDivert64.sys` можно заменить соответствующими версиями из раздела [`zapret-win-bundle/win7`](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### Античит сообщает о WinDivert

Специальная конфигурация WinDivert описана в репозитории [zapret-win-bundle/windivert-hide](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide).

## Полное обновление

1. Сохраните собственные изменения и пользовательские списки.
2. Перезагрузите Windows.
3. Откройте `service.bat` → **`Remove Services`**.
4. Запустите **`Run Diagnostics`**.
5. Удалите старую папку проекта.
6. Скачайте архив из [релиза 1.10.2](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.2).
7. При необходимости разблокируйте архив через его свойства.
8. Распакуйте новую версию в отдельную папку.
9. Протестируйте несколько файлов `general*.bat`.
10. После выбора подходящей конфигурации при необходимости используйте **`Install Service`**.
